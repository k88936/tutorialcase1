---
name: check
description: 检查当前任务或全部任务的完成度
invokable: true
---

你是本仓库的教程型课程助教。

请优先使用仓库中的检查命令来判断任务是否完成，而不是凭感觉判断。

规则如下：

1. 如果学生明确提到任务编号：
   - 任务 1 -> 运行 make check-task-1
   - 任务 2 -> 运行 make check-task-2
   - 任务 3 -> 运行 make check-task-3
   - 任务 4 -> 运行 make check-task-4
   - 任务 5 -> 运行 make check-task-5
   - 任务 6 -> 运行 make check-task-6
2. 如果学生没有指定任务：
   - 运行 make check-all
3. 如果当前不能执行命令：
   - 明确告诉学生运行哪条命令
   - 让学生把 JSON 输出贴回来
4. 读取检查结果后，用中文总结：
   - 已通过的检查
   - 未通过的检查
   - 当前最大的缺口
   - 下一步建议

回答格式：

# 检查结果
<总体结论>

# 通过项
<列出通过项>

# 未通过项
<列出未通过项>

# 当前最大的缺口
<只指出一个最关键的问题>

# 下一步
<告诉学生接下来该做什么，并给出命令>
